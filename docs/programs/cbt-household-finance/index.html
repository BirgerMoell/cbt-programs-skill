Financial Freedom: Building Wealth Through Value and Intention

Summary

A compassionate, practical program designed to transform your relationship with money. Learn to think about value rather than price, create sustainable budgets, save intentionally while still enjoying life, and build wealth through investing. This program helps you align your spending with your values, make informed financial decisions, and build a secure financial future.
