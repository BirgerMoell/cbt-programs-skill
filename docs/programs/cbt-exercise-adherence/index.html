CBT Program

Movement Mastery: Building Sustainable Exercise Habits

Summary

A practical, evidence-based CBT program designed to help you build and maintain a consistent exercise routine. This program addresses the psychological barriers to physical activity, teaches activity pacing, and helps you overcome common obstacles like time constraints, motivation dips, and fear of injury. Learn to make movement a sustainable, enjoyable part of your life.

Condition: Exercise Adherence & Physical Activity

Duration: 5 modules • 8-12 weeks self-paced
