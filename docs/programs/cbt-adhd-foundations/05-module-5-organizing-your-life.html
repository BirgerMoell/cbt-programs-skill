Module 5 • Organizing Your Life

Overview
  • External order supports internal calm. Create "homes" for key items and declutter in short, repeatable sprints.
  • Keep paper moving with a simple Inbox → Action → File flow.
Key Takeaways
  • Systems beat memory. Labels beat guesses.
  • Short, timed sessions trump heroic marathons.

No narrative sections.

Exercises
  • Choose one small, bounded area (one shelf/drawer/surface). Do a 15‑minute declutter using Keep / Relocate‑Action / Donate‑Discard.
  • Define "homes" for 3–5 frequently misplaced items; label if useful.
  • Set up your paper "Inbox" and "Action" trays if missing.
Homework
  • Run two 15‑minute declutters on the same area; process "Relocate‑Action" items immediately after.
  • Process your paper Inbox twice using Action / File / Discard; add actions to your list.
  • Track how often key items return to their "homes"; adjust placements if friction remains.
  • Reflect on space ↔ mood/focus link this week.
