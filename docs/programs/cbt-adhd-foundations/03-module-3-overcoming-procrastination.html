Module 3 • Overcoming Procrastination

Overview
  • Procrastination is an emotion regulation strategy, not a moral failure. Reduce overwhelm and starting becomes possible.
  • Break tasks into physical, first‑move actions and use the 5‑Minute Rule to cross the start line.
  • Link small steps to existing cues or rewards to harness momentum.
Key Takeaways
  • Tiny, concrete first actions dissolve avoidance.
  • Five minutes often becomes fifteen—but credit yourself even when it doesn’t.

No narrative sections.

Exercises
  • Paper & pen breakdown: pick one avoided task and list major steps → micro‑steps → circle the absolute first physical action.
  • Schedule one 5‑minute start on that first action today. Timer on.
  • Create a "link": pair a small step with a frequent cue (e.g., "after coffee, open the doc and write one sentence").
Homework
  • Break down two additional tasks this week. Identify the first physical action for each.
  • Apply the 5‑Minute Rule 3–5 times. Log start, stop/continue, and feelings after.
  • Experiment with one cue/reward pair daily; note which pairings help you return.
