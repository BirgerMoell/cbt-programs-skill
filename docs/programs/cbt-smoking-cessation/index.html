Freedom from Smoking: A CBT Approach to Quitting

Summary

An evidence-based CBT program designed to help you quit smoking and stay quit. This program addresses the psychological and behavioral aspects of smoking, teaches craving management techniques, provides relapse prevention strategies, and helps you build a smoke-free identity. Learn to break free from nicotine dependence and create a healthier life.

Condition: Smoking Cessation

Duration: 6 modules • 8-12 weeks self-paced
