Key Takeaways
  • Over-explaining is a trauma response; keep it simple.
  • Assertiveness is kind; clear is kind.
  • You can be firm and loving at the same time.

Stop JADE-ing

When we set a boundary, we often JADE: Justify, Argue, Defend, Explain. 'I can't come because my cat is sick and I'm tired and...' You are handing them ammunition to argue.

Stop JADE-ing. 'I can't make it tonight.' Simple. Clean. Strong. It feels rude, but it is actually respectful.
