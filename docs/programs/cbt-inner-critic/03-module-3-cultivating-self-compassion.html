Module 3 • Cultivating Self-Compassion

Overview
  • This module focuses on building self-compassion as a counterbalance to the inner critic. You will learn about the benefits of self-compassion and how to practice it.
  • We will introduce exercises that promote kindness and understanding towards oneself, which can help reduce self-criticism.
  • Developing a self-compassionate mindset will foster a more supportive inner dialogue.
Key Takeaways
  • Understand the principles of self-compassion.
  • Learn practical exercises to increase self-compassion.
  • Recognize the relationship between self-compassion and reduced self-criticism.

No narrative sections.

Exercises
  • Practice self-compassionate letter writing to yourself.
  • Engage in guided self-compassion meditations.
  • Use affirmations to reinforce self-compassionate thinking.
Homework
  • Write a self-compassionate letter addressing a recent instance of self-criticism.
  • Set aside time each day for a self-compassion meditation.
  • Reflect on changes in your self-talk after practicing self-compassion.
