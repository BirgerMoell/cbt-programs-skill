CBT Programs Library

Browse full CBT programs and guides. Use them in a browser, then return to chat to work through exercises with the virtual CBT coach.

How To Load The Skill

Codex (this app)

  • Place the skill at /Users/birger/skills/cbt-programs.
  • In chat, say: Use cbt-programs to help me with GAD.
  • Open program pages here, then paste your exercise answers into chat.

ClawDBot

  • Place the skill folder in <workspace>/skills (highest precedence) or ~/.clawdbot/skills.
  • If you keep it elsewhere, add the folder to skills.load.extraDirs in ~/.clawdbot/clawdbot.json.
  • Start a new session so the skills snapshot refreshes.
  • In chat, ask: Use cbt-programs to help me with GAD.

Clawdhub (install)

  • Install the CLI: npm i -g clawdhub or pnpm add -g clawdhub.
  • Search for a skill: clawdhub search "cbt".
  • Install: clawdhub install <skill-slug>.
  • Start a new session so ClawDBot picks up the new skill.

Clawdhub (publish)

  • From the skill folder, run: clawdhub publish ./cbt-programs --slug cbt-programs --name "CBT Programs" --version 1.0.0 --tags latest.
  • Use --changelog to add release notes (can be empty).

Getting Started (non-technical)

  • Open a program in your browser from the Programs list below.
  • Read the module, then answer the exercise prompts.
  • Paste your answers into chat to get feedback and continue.
